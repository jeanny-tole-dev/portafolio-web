# Portafolio Web Profesional - Jeanny Paola Tole

Bienvenido al repositorio oficial del **Portafolio Web Profesional** de **Jeanny Paola Tole Oliveros** — *Diseñadora Visual & Desarrolladora Web Fullstack*.

Este proyecto es una plataforma interactiva, responsiva y de alto rendimiento diseñada para presentar proyectos de desarrollo frontend, branding visual, experiencias 3D interactivas y validación técnica.

## 🚀 Características Principales

- ⚡ **Integración en Tiempo Real con GitHub API**: Sincronización automática de perfil, estadísticas y repositorios públicos.
- 🎨 **Diseño Editorial & UI/UX Premium**: Estética moderna en modo oscuro (*Dark Mode*) basada en tonos naranja durazno (`#ff7849`) y magenta lila (`#d946ef`).
- 🎠 **Carrusel de Proyectos & Tarjetas Flip 3D**: Presentación doble cara para proyectos con vista de cliente, especificaciones técnicas y mini-carrusel de fotografías/videos.
- 🌐 **Sección Interactiva de Laboratorio 3D**: Mención e integración de Three.js y proyectos e-commerce con gestión de roles.
- 📱 **100% Responsivo**: Adaptación fluida a dispositivos móviles, tablets y monitores de alta resolución.
- 🤖 **Automatización CI/CD**: Despliegue automático en **GitHub Pages** mediante GitHub Actions.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5 & CSS3**: Semántica HTML5 avanzada, CSS Grid, Flexbox, variables CSS y animaciones fluidas.
- **JavaScript (ES6+)**: Consumo de APIs REST (GitHub API), manipulación asíncrona del DOM y lógica modular de eventos.
- **Three.js & WebGL**: Integración de entornos y laboratorios tridimensionales.
- **Git & GitHub Actions**: Control de versiones y flujo de despliegue continuo.

## 📁 Estructura del Proyecto

```
portafolio-web/

├── img/                    # Galería de imágenes y demostraciones multimedia

    └── workflows/
        └── deploy.yml      # Workflow de despliegue continuo a GitHub Pages
```
